# RealisticCombat для Roblox Studio

Готовая сервер-авторитетная система для пушки и брони: баллистический полёт, падение скорости и гравитация, угол встречи, приведённая толщина брони (RHAe), пробитие, потеря энергии, рикошеты, деградация брони, осколочно-фугасный урон и несколько типов снарядов.

> Это игровая модель. Значения боеприпасов намеренно сбалансированы для Roblox и **не являются** инструкциями, спецификациями или данными для реального оружия.

## Возможности

- **Сервер рассчитывает всё важное**: позицию ствола, скорострельность, боезапас, столкновения, урон и бронепробитие. Клиент рисует только трассеры/вспышки.
- **Броня на атрибутах**: толщина в мм, материал, прочность, разнесённая и динамическая защита — без скрипта для каждой детали.
- **Угол брони**: чем касательнее попадание, тем выше эффективная толщина и вероятность рикошета.
- **Снаряды из коробки**: `AP_30MM`, `HE_30MM`, `HEAT_30MM`, `APFSDS_30MM`.
- **Свои типы**: добавьте определение в один ModuleScript `CustomShells`; сервер использует его для баллистики, а клиент — только для названий HUD.
- **HUD и управление**: ЛКМ — выстрел, `R` — перезарядка, `1`–`4` — выбор совместимого типа при пустом магазине.

## Быстрый запуск

1. Установите [Rojo](https://github.com/rojo-rbx/rojo) и синхронизируйте `default.project.json` с Roblox Studio.
2. В `StarterPack` создайте `Tool` и поставьте ему атрибут `CombatWeapon = true`.
3. Добавьте в Tool `Attachment` (или `BasePart`) с именем **`Muzzle`**. Его `WorldCFrame.LookVector` — направление ствола.
4. Скопируйте `ReplicatedStorage/Combat/Examples/WeaponConfig` в Tool и оставьте имя `WeaponConfig`.
5. Задайте Tool запас снарядов как атрибуты:
   - `Ammo_AP_30MM = 48`
   - `Ammo_HE_30MM = 24`
   - `Ammo_HEAT_30MM = 8`
   - `Ammo_APFSDS_30MM = 12`
6. Запустите тест сервера (Play). Нажмите `R`, выберите тип клавишами `1`–`4` и стреляйте.

`CombatBootstrap.server.lua` сам создаёт необходимые RemoteEvent в `ReplicatedStorage/Combat/CombatRemotes`. Создавать их в Studio вручную не нужно.

## Настройка брони

Выделите деталь брони (`BasePart`) либо её модель и добавьте атрибуты:

| Атрибут | Тип | Пример | Назначение |
|---|---:|---|---|
| `ArmorThicknessMm` | Number | `45` | Физическая толщина пластины в миллиметрах. |
| `ArmorMaterial` | String | `Steel` | Материал из списка ниже. |
| `ArmorIntegrity` | Number | `1` | Текущая целостность от 0 до 1. Система уменьшает её при попаданиях. |
| `ArmorHitPointsJoules` | Number | `600000` | Необязательно: запас устойчивости к повторным попаданиям. |
| `ReactiveArmor` | Boolean | `true` | Усиливает защиту от кумулятивных снарядов. |
| `ReactiveArmorMultiplier` | Number | `1.9` | Необязательно: множитель ДЗ против HEAT. |
| `SpacedArmorMm` | Number | `20` | Дополнительная разнесённая защита против HEAT. |
| `CanRicochet` | Boolean | `false` | Принудительно включить/выключить рикошет. |

Материалы: `Steel`, `CastSteel`, `Titanium`, `Aluminum`, `Ceramic`, `UHMWPE`, `Concrete`, `Brick`, `Wood`, `Glass`. Если атрибуты не заданы, материал детали Roblox и её наименьший размер дают разумную карту-геометрию по умолчанию. Для важных бронелистов всегда указывайте толщину явно.

Для шлема или бронежилета удобно поставить атрибуты на `Accessory`/модель брони: сервис найдёт их по предкам задетой детали. Неприкрытые части персонажа считаются мягкой тканью и получают урон только после успешного проникновения.

## Настройка Tool

Все поля ниже можно определить в ModuleScript `WeaponConfig` (см. пример) или переопределить одноимённым атрибутом Tool.

| Поле | Значение по умолчанию | Смысл |
|---|---:|---|
| `MuzzleName` | `Muzzle` | Имя Attachment/BasePart на конце ствола. |
| `MagazineSize` | `12` | Ёмкость магазина. |
| `AmmoInMagazine` | `0` | Начальное количество в магазине. |
| `ReloadTimeSeconds` | `2.5` | Время перезарядки. |
| `FireIntervalSeconds` | `0.25` | Минимальная пауза между выстрелами. |
| `MaxAimAngleDegrees` | `89` | Максимальное отклонение запроса игрока от направления ствола. |
| `AmmoTypes` | из `WeaponConfig` | Список id через запятую, например `AP_30MM,HE_30MM`. |
| `Ammo_<ID>` | `0` | Боезапас каждого типа, например `Ammo_AP_30MM`. |

Один магазин содержит один тип. Чтобы сменить тип, сначала израсходуйте магазин, нажмите `1`–`4`, затем `R`. Это исключает бесплатную подмену уже заряженного боеприпаса.

## Добавление боеприпаса

Откройте `src/ReplicatedStorage/Combat/CustomShells/init.lua` и добавьте таблицу в возвращаемый массив. Полное описание полей и пример — в [docs/ADDING_AMMO.md](docs/ADDING_AMMO.md). Затем включите id в `AllowedShells` вашего `WeaponConfig` и добавьте Tool атрибут `Ammo_<ID>`.

## Структура

```text
src/
├── ReplicatedStorage/Combat/
│   ├── Shared/                 # каталог боеприпасов и математическая модель
│   ├── CustomShells/            # проектные боеприпасы
│   └── Examples/WeaponConfig.lua
├── ServerScriptService/Combat/
│   ├── CombatBootstrap.server.lua
│   └── Services/                # оружие, броня, урон, снаряды
└── StarterPlayer/StarterPlayerScripts/
    └── CombatClient.client.lua  # HUD, ввод, только косметические эффекты
```

Подробный чек-лист интеграции: [docs/ROBLOX_SETUP.md](docs/ROBLOX_SETUP.md).
