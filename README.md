# Кадр Studio

Desktop-версия редактора AI-мультфильмов на Electron.

## Сборка Windows EXE

Требуется Windows 10/11, Node.js 20 или новее и интернет для первой установки зависимостей.

1. Распакуйте проект и откройте терминал в папке проекта.
2. Выполните `npm install`.
3. Выполните `npm run dist:win`.
4. Установщик и portable EXE появятся в папке `release/`.

Для запуска из исходников: `npm run desktop:dev`.

Сборка EXE из этого рабочего окружения не удалась: загрузка бинарного Electron с GitHub оборвалась на сетевом TLS-соединении. Исходники и конфигурация упаковки подготовлены; сборку можно выполнить на Windows командами выше.
