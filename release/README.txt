КАДР STUDIO — ПАКЕТ РЕЛИЗА

В этой папке находится скрипт для сборки Windows EXE: СОБРАТЬ_EXE.bat.
Для сборки установите Node.js 20 или новее, затем запустите этот BAT-файл.
Установщик и portable-версия появятся в этой же папке после сборки.

Исходники находятся на уровень выше: src, electron, package.json.
