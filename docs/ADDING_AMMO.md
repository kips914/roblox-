# Добавление типов снарядов

Все кастомные боеприпасы находятся в `src/ReplicatedStorage/Combat/CustomShells/init.lua`. Каталог читает этот модуль на сервере (для баллистики) и на клиенте (только для названий HUD). Клиент не может зарегистрировать, изменить или подменить характеристики, которые использует сервер.

## Минимальный пример

```lua
return {
    {
        id = "AP_57MM",
        displayName = "57 mm AP",
        family = "Armour Piercing",
        caliberMm = 57,
        massKg = 2.8,
        muzzleVelocityMps = 1000,
        penetrationAtZeroMm = 115,
        penetrationExponent = 1.16,
        directDamage = 150,
        maxPenetrations = 3,
        ricochetStartAngleDegrees = 64,
        ricochetEnergyRetention = 0.54,
        armorDamageFactor = 1.2,
        tracerColor = Color3.fromRGB(255, 200, 100),
    },
}
```

`id` должен быть уникальным и состоять только из букв, цифр, `_` или `-`. После добавления id внесите его в `AllowedShells` вашего `WeaponConfig` и создайте у Tool атрибут `Ammo_AP_57MM`.

## Поля определения

| Поле | Ед. | Обяз. | Описание |
|---|---:|:---:|---|
| `id` | — | да | Уникальный технический id. |
| `displayName` | — | да | Название в HUD. |
| `family` | — | нет | Категория для интерфейса/сортировки. |
| `caliberMm` | мм | нет | Калибр, влияет на размер трассера. |
| `massKg` | кг | нет | Масса для кинетической энергии и деградации брони. |
| `muzzleVelocityMps` | м/с | нет | Начальная скорость. |
| `penetrationAtZeroMm` | мм RHAe | нет | Пробитие при нулевой дистанции. |
| `penetrationExponent` | — | нет | Насколько пробитие уменьшается со скоростью/дальностью у кинетики. |
| `directDamage` | HP | нет | Базовый урон Humanoid после успешного проникновения. |
| `maxPenetrations` | шт. | нет | Максимум успешно пробитых объектов. |
| `maxDistanceM` | м | нет | Дистанция самоуничтожения. |
| `maxLifetimeSeconds` | с | нет | Максимальное время существования. |
| `airDrag` | — | нет | Упрощённый коэффициент торможения в воздухе. |
| `ricochetStartAngleDegrees` | ° | нет | С этого угла от нормали вероятность рикошета начинает расти. |
| `ricochetEnergyRetention` | 0–0.95 | нет | Доля скорости после рикошета. `0` отключает рикошет. |
| `armorDamageFactor` | — | нет | Множитель потери `ArmorIntegrity`. |
| `tracerColor` | — | нет | `Color3` трассера и вспышек. |
| `explosiveMassKg` | кг | нет | Масса игрового ВВ для радиального урона. |
| `explosionRadiusM` | м | нет | Радиус игрового взрыва. |
| `detonateOnImpact` | bool | нет | Подрыв при первом столкновении (типично HE). |
| `shapedCharge` | bool | нет | HEAT: пробитие слабо зависит от скорости, не рикошетит. |
| `detonateAfterPenetrationM` | м | нет | Дистанция до подрыва после первого успешного проникновения. |

Все поля кроме `id` и `displayName` имеют безопасные значения по умолчанию. Реестр проверяет числа и диапазоны при запуске; некорректный кастомный снаряд будет пропущен с предупреждением в Output.

## Поведение типов

- **AP / APFSDS**: кинетические снаряды. Пробитие зависит от остаточной скорости, после каждого пробития скорость падает. При касательном ударе возможен рикошет.
- **HE**: взрывается на первом препятствии, наносит радиальный урон без Roblox `Explosion`, поэтому не разрушает произвольно Weld/Joint.
- **HEAT**: сначала проверяет струю против приведённой толщины, затем создаёт небольшой фугасный эффект. `ReactiveArmor` и `SpacedArmorMm` снижают его эффективность.

Модель предназначена для предсказуемого игрового баланса, а не для моделирования реальных боеприпасов.
